MIDI Piano Jaramillo para macOS
================================

Contenido
---------
- MIDI Piano Jaramillo.dmg: instalador macOS.
- README_macOS.txt: este documento.

Compatibilidad
--------------
- macOS 12 o superior.
- Universal: Apple Silicon (arm64) e Intel (x86_64).
- La app esta firmada ad-hoc localmente, no notarizada por Apple.

Instalacion
-----------
1. Abre el archivo DMG.
2. Arrastra "MIDI Piano Jaramillo.app" a la carpeta Applications.
3. Abre la app desde Applications.

Si macOS muestra una advertencia de seguridad
---------------------------------------------
Al no estar notarizada, macOS puede mostrar "no se puede abrir porque Apple no puede verificar...".
Para abrirla:
1. Ve a System Settings > Privacy & Security.
2. Busca el aviso de MIDI Piano Jaramillo.
3. Pulsa Open Anyway.

Tambien puedes hacer clic derecho sobre la app y elegir Open.

Descripcion
-----------
MIDI Piano Jaramillo es una aplicacion de practica y visualizacion armonica para MIDI.
Incluye vistas de piano y diapason de guitarra, reconocimiento de acordes en vivo, cifrado
principal y alternativo, escalas y acordes pregrabados, etiquetas funcionales de intervalos,
alertas de 9m segun el contexto armonico y controles de octavas y registro. La seccion Estudio
permite grabar, importar, guardar y exportar ejercicios MIDI, reproducirlos con velocidad
regulable y practicarlos por pasos o en modo guiado desde la vista de piano o guitarra.

Notas
-----
- Para entrada MIDI en vivo, conecta tu teclado antes de abrir la app o usa el menu MIDI para refrescar entradas.
- Las preferencias visuales se guardan localmente en el perfil del usuario.
- No requiere instalar Python ni dependencias adicionales.
