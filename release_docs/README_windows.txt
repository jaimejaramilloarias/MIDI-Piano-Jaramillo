MIDI Piano Jaramillo para Windows
=================================

Contenido
---------
- MIDI Piano Jaramillo/MIDI Piano Jaramillo.exe: aplicacion para Windows.
- MIDI Piano Jaramillo/_internal/: dependencias incluidas.
- README_windows.txt: este documento.

Compatibilidad
--------------
- Windows 10 u 11, 64-bit.
- No requiere instalar Python.

Instalacion y uso
-----------------
1. Descomprime este ZIP.
2. Abre la carpeta "MIDI Piano Jaramillo".
3. Ejecuta "MIDI Piano Jaramillo.exe".
4. Para MIDI en vivo, conecta tu teclado antes de abrir la app o refresca entradas desde el menu MIDI.

Descripcion
-----------
MIDI Piano Jaramillo es una aplicacion de practica y visualizacion armonica para MIDI.
Incluye vistas de piano y diapason de guitarra, reconocimiento de acordes en vivo, cifrado
principal y alternativo, escalas y acordes pregrabados, etiquetas funcionales de intervalos,
alertas de 9m segun el contexto armonico y controles de octavas y registro.

Nota sobre seguridad
--------------------
El primer .exe generado por PyInstaller puede activar Windows SmartScreen porque no esta firmado
con certificado comercial. Si Windows muestra una advertencia, usa "More info" y luego "Run anyway"
si confias en el origen del archivo.
