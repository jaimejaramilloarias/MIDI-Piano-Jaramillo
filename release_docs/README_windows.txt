MIDI Piano Jaramillo para Windows
=================================

Contenido
---------
- MIDI-Piano-Jaramillo-Windows-Setup.exe: instalador para Windows.
- README_windows.txt: este documento.

Compatibilidad
--------------
- Windows 10 u 11, 64-bit.
- No requiere instalar Python.

Instalacion y uso
-----------------
1. Descomprime este ZIP.
2. Ejecuta "MIDI-Piano-Jaramillo-Windows-Setup.exe".
3. Sigue los pasos del instalador.
4. Para MIDI en vivo, conecta tu teclado antes de abrir la app o refresca entradas desde el menu MIDI.

Descripcion
-----------
MIDI Piano Jaramillo es una aplicacion de practica y visualizacion armonica para MIDI.
Incluye vistas de piano y diapason de guitarra, reconocimiento de acordes en vivo,
cifrado principal y alternativo, escalas y acordes pregrabados, etiquetas funcionales
de intervalos, alertas de 9m segun el contexto armonico y controles de octavas y registro.
La seccion Estudio permite grabar, importar, guardar y exportar ejercicios MIDI, MusicXML
o MXL, reproducirlos con su ritmo original o practicarlos en modo guiado desde la vista de
piano o guitarra.

Nota sobre seguridad
--------------------
El instalador no esta firmado con certificado comercial y puede activar Windows SmartScreen.
Si Windows muestra una advertencia, usa "More info" y luego "Run anyway" si confias en el
origen del archivo.
